# Striker Royale: WebSocket Soccer Game

A real-time physics-based multiplayer soccer game built with Vue and WebSockets. Playable in any modern browser on desktop/mobile.

**[Play it Here](https://s25-websocket-zakb3005-production.up.railway.app)**

Striker Royale is a real-time, physics-based multiplayer soccer game built from scratch using Node.js, WebSockets, Matter.js, and HTML5 Canvas. The app features smooth client-server synchronization, server-sided physics using Matter.js, and intuitive drag-and-release controls for player movement. The server manages authoritative game state, while the client renders gameplay with visual effects like trajectories and linear-interpolated text animations. All communication between players is handled via a lightweight WebSocket protocol to ensure fast, consistent multiplayer interaction.  

- Playable on any modern browser
- Supported on mobile devices

## How to Play
- **Enter your Name**: Players get assigned on auto-balanced teams
- **Mouse or Touch**: Drag to aim and shoot your icon
- **Scoring**: Shoot the ball into the opposing teams goal. 3 Goals to win
